ATTACK PATH
  1. nmap -p- (FTP, HTTP, SSH on 2222)
  2. gobuster finds /simple
  3. CMS Made Simple 2.2.8
  4. CVE-2019-9053 SQLi dumps and cracks mitch's hash
  5. SSH as mitch on 2222
  6. sudo vim NOPASSWD
  7. root

Simple CTF is an easy Linux box with an old CMS Made Simple site. I find the version, match it to an unauthenticated SQL injection, and use a public exploit to dump and crack the admin password. A note on anonymous FTP says the same weak password is used for the system user, so I log in over SSH on port 2222. mitch can run vim as root with sudo, which gives a root shell.

#Q1. How many services are running under port 1000?

1Scan the top 1000 ports

zsh — zero@444
┌──(zero㉿444)-[~/THM/simple-ctf]
└─$ nmap -sVC --top-ports 1000 -Pn -T4 simple.thm

simple.thm points to the target IP in my /etc/hosts. -Pn skips the ping check, and -sVC adds versions and default scripts.

#Q3 + Q4. What's the CVE, and what kind of vulnerability is it?

1Brute-force web directories

The web root is only the Apache default page, so I look for hidden paths.

2Open /simple and read the version

I open http://simple.thm/simple/ in the browser. The site runs CMS Made Simple.

The footer at the bottom of the page shows the exact version.

3Search the version for CVEs

I search for CMS Made Simple 2.2.8 cve.

CVE-2019-9053 is an unauthenticated, time-based blind SQL injection in the News module. That answers Q4 too: the bug class is sqli.

This step has no screenshot; I wrote it from my commands. The note says mitch uses one weak password for the CMS and the system user, so a cracked CMS password should also work on SSH.

2Get a Python 3 version of the exploit

The original Exploit-DB script (46635) is Python 2. This fork works with Python 3 and has the same -u, -w and --crack options: github.com/Perseus99999/CVE-2019-9053-working-

3Run the exploit and crack the hash

zsh — zero@444
┌──(zero㉿444)-[~/THM/simple-ctf]
└─$ python3 exploit.py -u http://simple.thm/simple/ --crack \
    -w /usr/share/wordlists/rockyou.txt

It leaks the salt, the username mitch, the email and the password hash, then cracks the hash with rockyou. The password is ••••••.

Why it works

The News module puts the m1_idlist parameter straight into a SQL query. The script injects conditions with a sleep, so a slow reply means "true", and it rebuilds each value one character at a time. CMSMS stores md5(salt + password), so with the salt known the script hashes each rockyou word the same way and compares.

4Check the creds on the CMS admin panel

I log in at http://simple.thm/simple/admin/login.php as mitch. I do not need the admin panel for the solve, but it proves the creds are real.

#Q9 + Q10. What gives a privileged shell, and what's the root flag?

1Check sudo rights

ssh — mitch@simple.thm
$ sudo -l
User mitch may run the following commands on Machine:
    (root) NOPASSWD: /usr/bin/vim

mitch can run /usr/bin/vim as root with no password.

2Escape from vim to a root shell

ssh — mitch@simple.thm
$ sudo vim -c ':!/bin/sh'
# whoami
root

A quick search for vim sudo privesc (GTFOBins) gives this one-liner.

Why it works

sudo starts vim as root. -c runs a vim command at start, and :! runs a shell command, so /bin/sh starts with root rights. Any NOPASSWD tool that can run commands works the same way.
