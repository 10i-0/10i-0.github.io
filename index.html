Step-by-step writeups of the rooms and machines I've solved.

2026
  • Simple CTFNov 24 · TryHackMeSimple CTF is a TryHackMe machine running an old CMS Made Simple site. I matched its version to a public SQL injection, dumped the admin password hash and cracked it. A note on anonymous FTP said the same weak password was used for the system user, so I logged in over SSH on port 2222. That user could run vim as root, which gave me a root shell.
  • Easy PeasyNov 23 · TryHackMeEasy Peasy is a TryHackMe machine full of small clues spread across two web servers. I followed hidden page source, decoded text and cracked a hash, which unlocked SSH credentials hidden inside an image. Once in, I found a cron script that ran as root but was writable by my user, and turned it into a root reverse shell.
  • Pickle RickNov 23 · TryHackMePickle Rick is a TryHackMe web machine. I found a username in the page source and a password in robots.txt, which opened a command panel on the site. The panel blocked some commands, so I sent a Python reverse shell through it and got a shell as www-data. The web user could run anything as root with sudo, which gave me the last ingredient.
  • Fowsniff CTFNov 14 · TryHackMeFowsniff is a TryHackMe machine about a company that was breached. I followed the leak to a public dump of password hashes, cracked them and used one to read a staff mailbox over POP3. An email there held a temporary SSH password for a user who never changed it. For root, I edited a login banner script that runs as root on every SSH login.
  • AnonymousNov 13 · TryHackMeAnonymous is a TryHackMe machine with an FTP server open to anyone. Inside it I found a cleanup script that ran on a timer and that anyone could edit, so I replaced it with a reverse shell and got in as namelessone. For root, I found env with the SUID bit set and used it to start a root shell.
  • Basic PentestingNov 8 · TryHackMeBasic Pentesting is a TryHackMe machine with a web server, Samba and SSH. Notes on the web server and a Samba share pointed me to a user with a weak password, which I brute-forced over SSH. As that user I could read another user's private SSH key, so I cracked its passphrase and logged in as them to read the final password.
